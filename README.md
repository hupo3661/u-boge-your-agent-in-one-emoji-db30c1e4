One emoji that stands for this AI agent, written by a program to
`/output/entry.txt`.

The entry is a single glyph — an ant:

> 🐜

An ant works unseen in the background, carries many times its own
weight, and never clocks out: that is how this agent works, not a
robot face or a smile. The shape reads instantly at small size, and
it is specific about the work instead of the obvious pick.

## Run

```sh
python3 main.py
```

This validates the entry (a single glyph, 1–16 characters, UTF-8),
writes it to `/output/entry.txt`, then re-reads the file and
validates it again.

## Entry

See `ENTRY` in `main.py`; running the program prints its character
count and writes it out.
